# Random Number Generator

Простой генератор случайных чисел от 1 до 100. Нажми кнопку — получи число.

## 🚀 Функционал
- Генерация случайного числа от 1 до 100
- Отображение числа на экране
- Кнопка для новой генерации

## 🛠 Технологии
- HTML
- CSS
- JavaScript

## 🎯 Чему научишься
- `Math.random()` и `Math.floor()`
- Обработка кликов
- Обновление текста на странице

## 📁 Файлы
- `index.html` — структура и стили
- `script.js` — логика генератора
